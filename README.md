# maturitni_prace - 2026/27

Maturitni práce IT4

Účel aplikace je evidence 
a měření času práce jednotlivých pracovníků
na určitých strojích a zakázkách pomocí načtení QR kódů.

Webová aplikace:

Funkce:
- Při načtení QR kódu otevřít aplikaci
- Ověřil platnost QR kódu,
- Zaznamenal uživatele, stroj a zakázku,
- Uložil čas načtení,
- Případně ukončil předchozí práci a spočítal její délku,
- Vygeneroval nový QR token a zneplatnil původní kód.
